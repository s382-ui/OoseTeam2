# 비안전교육 관리 구현

작성일: 2026-06-19

## 적용 범위

SDD 4.2~4.7을 기준으로 다음 기능을 구현한다.

- 사용자 관리
- 연구실 관리
- 화학물질 관리
- 폐기물 관리
- 일상점검 관리
- 점검 관리(정기·정밀·수시)

안전교육 관리 코드는 이 작업 범위에서 변경하지 않는다.

## 공통 화면 기능

`frontend/src/components/EntityManagementPage.jsx`는 관리 화면에서 다음 기능을 제공한다.

- 등록 폼과 입력 초기화
- 관리별 다중 검색 조건
- 조회 결과 건수 및 결과 없음 안내
- 목록의 상세 정보 확인
- 체크리스트 기존 항목 복사

## 관리별 구현

### 사용자 관리

- 단건 등록, 조건 조회, 상세 조회
- CSV 파일을 이용한 사용자 대량 등록
- CSV 필수 열: `userId`, `userName`, `department`, `role`, `contact`, `email`, `accountStatus`
- 파일 내부 ID 중복과 기존 사용자 ID 중복 시 전체 등록 중단

학내 데이터베이스 접속 정보가 없으므로 SDD의 학번/사번 외부 조회는 구현하지 않고 관리자가 확인한 정보를 직접 입력한다.

### 연구실 관리

- 연구실명, 건물, 호실, 소속, 책임자, 사용 여부 조건 조회
- 책임자 사용자 ID가 사용자 데이터에 존재하는지 검증
- 동일 건물·층·호실의 활성 연구실 중복 등록 방지

### 화학물질 관리

- SDD `ChemicalMaster` 필드에 맞춰 제조사명, 물질명, CAS 번호, 함유량, MSDS 경로, 성분분석표 경로, 상태 관리
- CAS 번호 중복 등록 방지
- 제조사명, 물질명, CAS 번호, 상태 조건 조회

산업안전보건공단 API 키와 문서 저장소가 없으므로 외부 MSDS 조회와 실제 파일 업로드 대신 문서 경로/파일명을 저장한다.

### 폐기물 관리

- SDD 필드명인 분류 코드, 분류 유형, 성상 정보, 처리 방법, 관련 법규, 사용 여부 적용
- 유형, 코드, 명칭, 성상, 사용 여부 조건 조회

### 일상점검 관리

- 항목명, 분야명, 배점, 점검 유형, 필수 여부, 사용 여부 관리
- 동일 항목명·분야·점검 유형 중복 등록 방지
- 기존 항목 복사 후 새 ID로 등록

### 점검 관리

- SDD 필드명인 분류 코드, 분류명, 상세 설명, 사용 여부 적용
- 코드, 분류명, 상세 설명, 사용 여부 조건 조회

## API

- 공통 등록·조회: `GET`, `POST /api/<resource>`
- 사용자 대량 등록: `POST /api/users/bulk`

## 데이터 초기화 주의

이번 변경으로 화학물질, 폐기물, 체크리스트, 점검분야 JSON 필드명이 SDD에 맞게 변경되었다.
이전 스키마로 생성된 `backend/data`가 있으면 백엔드를 종료하고 해당 폴더를 삭제한 뒤 다시 실행해야 한다.
