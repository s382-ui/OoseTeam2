# 에이전트 진입 및 문서화 행동양식

작성일: 2026-06-11

## 목적

Claude, Codex 또는 다른 AI 에이전트가 이 프로젝트에 진입할 때 현재 구현 상태를 먼저 파악하고, 변경 이후 문서화를 누락하지 않도록 강제하는 작업 규칙이다.

이 문서는 프로젝트 변경을 수행하는 에이전트의 필수 체크리스트다. 코드만 수정하고 문서를 갱신하지 않는 작업은 완료로 보지 않는다.

## 진입 시 필수 절차

프로젝트에 들어온 에이전트는 작업 전에 다음을 수행한다.

1. `docs/implementation-review.md`를 읽고 현재 구현 범위와 한계를 확인한다.
2. `docs/run-guide.md`를 읽고 현재 실행, 빌드, 검증 방법을 확인한다.
3. `docs/documentation-maintenance.md`를 읽고 문서 분리 기준을 확인한다.
4. `docs/reference_mdFileList/`의 SRS, SDD, PMP, architecture 문서를 확인해 요구사항과 설계 기준을 파악한다.
5. `src/App.jsx`와 변경 대상 컴포넌트를 읽어 실제 구현이 문서와 일치하는지 확인한다.
6. `git status --short`로 기존 변경 사항을 확인하고, 사용자가 만든 변경을 되돌리지 않는다.
7. 요청이 기능 추가, 버그 수정, 리팩터링, UI 수정, 문서 변경 중 어디에 해당하는지 분류한다.
8. 작업 범위에 영향을 받는 문서를 먼저 식별한다.

## 변경 후 필수 문서화

다음 중 하나라도 해당하면 문서를 갱신해야 한다.

- 메뉴, 화면, 탭, 폼 필드, 테이블 컬럼이 추가/삭제/변경됨
- 상태 관리 방식, 데이터 저장 방식, API 연동 방식이 변경됨
- 검증 규칙, 삭제 정책, 권한 정책, 알림 정책이 변경됨
- 테스트 방법, 실행 명령, 빌드 방법이 변경됨
- 파일 구조 또는 컴포넌트 책임이 변경됨

갱신 대상은 기본적으로 다음 문서다.

- `docs/implementation-review.md`: 구현 범위, 아키텍처, 한계, 개선 권장사항 변경 시 갱신
- `docs/run-guide.md`: 설치, 실행, 빌드, 검증 명령 변경 시 갱신
- `docs/agent-entry-documentation-policy.md`: 에이전트 작업 규칙 변경 시 갱신
- `docs/documentation-maintenance.md`: 문서 분리 기준과 유지보수 원칙 변경 시 갱신
- `docs/reference_mdFileList/`: 원본 요구사항이나 설계 기준을 확인해야 하는 기능 변경 시 참조
- 추가 기능 문서: 특정 기능의 상세 규칙이 커지면 `docs/<feature-name>.md`로 분리

## 문서 분리 원칙

문서가 길어지거나 주제가 독립적으로 읽혀야 하면 기존 문서에 계속 누적하지 않는다. 새 문서를 만들고 기존 문서에는 링크와 요약만 남긴다.

상세 기준은 `docs/documentation-maintenance.md`를 따른다.

## 작업 완료 조건

에이전트는 최종 응답 전에 다음을 확인한다.

- 코드 변경이 있다면 관련 문서도 갱신했는가?
- 문서 변경이 실제 구현과 충돌하지 않는가?
- 테스트를 실행했거나, 실행하지 못했다면 이유와 대체 검증을 기록했는가?
- 새 한계나 기술 부채가 생겼다면 문서에 남겼는가?
- ChatDB 규칙이 활성화된 세션이라면 `chats/chat_<user>_YYYY-MM-DD.md`에 작업 결과를 기록했는가?

## 문서 작성 원칙

- 구현 사실과 계획을 구분한다.
- 아직 구현되지 않은 기능은 "현재 한계" 또는 "개선 권장사항"에 둔다.
- 파일 경로와 컴포넌트 이름은 실제 이름으로 쓴다.
- 테스트가 없으면 구체적인 테스트 2개 이상을 제안한다.
- 보안, 개인정보, 안전관리 이력처럼 운영 리스크가 있는 사항은 별도로 표시한다.

## Claude/Codex 응답 규칙

작업 완료 응답에는 최소한 다음을 포함한다.

- 변경한 파일
- 구현 또는 문서화한 핵심 내용
- 실행한 검증 명령과 결과
- 실행하지 못한 테스트가 있다면 사유
- 권장 커밋 메시지

이 프로젝트의 세션 지침이 ChatDB 출력 형식을 요구하는 경우, 최종 응답에는 다음 항목도 포함한다.

- ChatDB 항목 초안
- 파일 반영 명령
- 검증 체크리스트
- PR용 요약 한 줄
