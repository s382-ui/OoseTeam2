# Module Guide

## 1. 사용자 모듈

- 목적: 사용자 계정과 권한 정보를 관리한다.
- 중심 파일: `user/domain`, `user/application`, `user/infrastructure`, `user/presentation`
- 변경 기준: 계정 상태, 소속, 권한 체계가 바뀔 때 함께 수정한다.

## 2. 연구실 모듈

- 목적: 연구실 기본 정보와 책임자 정보를 관리한다.
- 중심 파일: `laboratory/...`
- 변경 기준: 연구실 식별자와 상태값이 바뀔 때 함께 수정한다.

## 3. 화학물질 모듈

- 목적: 화학물질 등록, 보관, 상태를 관리한다.
- 중심 파일: `chemical/...`
- 변경 기준: 보관 위치, 수량 단위, 위험 분류가 바뀔 때 함께 수정한다.

## 4. 폐기물 모듈

- 목적: 폐기물 발생과 보관, 처리 상태를 관리한다.
- 중심 파일: `waste/...`
- 변경 기준: 폐기물 분류와 처리 상태가 바뀔 때 함께 수정한다.

## 5. 점검 모듈

- 목적: 일상점검과 정기점검 흐름을 관리한다.
- 중심 파일: `inspection/...`
- 변경 기준: 점검 유형, 점검 결과, 대상 범위가 바뀔 때 함께 수정한다.

## 6. 안전교육 모듈

- 목적: 교육 이수와 교육 상태를 관리한다.
- 중심 파일: `education/...`
- 변경 기준: 교육 과정명, 대상자, 이수 상태가 바뀔 때 함께 수정한다.
